# APP 备案指引

本文是操作备忘，不构成法律意见。具体要求以工业和信息化部及接入服务商的最新规定为准。

## 1. 为什么需要备案

依据工业和信息化部关于移动互联网应用程序备案的要求，在中华人民共和国境内从事互联网信息服务的 APP，应由主办者履行备案手续；未履行备案手续的，不得从事相关互联网信息服务。自 2023 年 9 月起，新上架 APP 需先完成备案。即使应用本身没有后端服务器，只要在境内分发并提供服务，通常仍需要办理 APP 备案。

官方备案系统：<https://beian.miit.gov.cn>

## 3. 获取签名公钥与证书摘要

APP 备案通常需要填写签名证书的公钥和摘要信息。构建正式包后执行：

```powershell
apksigner verify --print-certs dist\ble-hr-viewer-1.1.0.apk
```

输出包含证书的 SHA-256、SHA-1 与 MD5 摘要。也可直接读取证书：

```powershell
keytool -printcert -jarfile dist\ble-hr-viewer-1.1.0.apk
```

或从密钥库导出：

```powershell
keytool -list -v -keystore D:\Keys\ble-hr-viewer-release.jks -alias <你的别名>
```

请妥善保管输出中的公钥与指纹。**包名、签名证书或主办者发生变更时，需要办理备案变更。**

## 4. 提交途径

1. 通过拟上架的应用商店或云服务商等接入服务商提交，通常由服务商协助核验材料。
2. 或通过工信部备案系统按其指引提交。

审核时间以备案系统与实际受理情况为准。取得备案号后：

- 在应用商店资料、官网和发布说明中展示备案号。
- 将备案号写入本地 `gradle.properties`（不要提交真实值也可以，按你的发布方式决定）：

```properties
app.filingNumber=京ICP备XXXXXXXX号-XXA
```

重新构建后，备案号会显示在应用内「设置 → 关于与合规」。

## 5. 常见退回原因

- 应用名称、包名、图标与安装包不一致。
- 签名证书信息与提交的 APK 不一致（例如提交了 Debug 包）。
- 隐私政策无法访问，或未说明收集的信息、权限和联系方式。
- 应用内未提供隐私政策入口，或首次启动未征得同意即申请权限。
- 服务器 / 域名信息与应用实际行为不符。

## 6. 上线前自查

- [ ] 使用 Release 签名包提交，包名与备案信息一致。
- [ ] 隐私政策 URL 可公开访问，内容与安装包行为一致。
- [ ] 首次启动先展示隐私提示，同意后才请求权限。
- [ ] 应用内可查看隐私政策、用户协议、开源许可与联系方式。
- [ ] 备案号已配置并展示（取得后）。
- [ ] 分发页面包含非医疗器械声明与安装包校验值。
